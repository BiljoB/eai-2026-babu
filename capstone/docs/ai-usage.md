# AI usage

## Tools used

I used AI assistance during the capstone development, along with Visual Studio Code (VS Code) and Windows PowerShell.

- AI assistance for coding guidance, fixing errors and understanding implementation problems.
- Visual Studio Code for writing and editing code and project documentation.
- PowerShell for running commands, installing dependencies and executing tests.

## What for

I used AI assistance mainly when I faced problems during development and needed help understanding or fixing them.

This included:
- Finding and fixing errors in the code.
- Understanding TypeScript errors and implementation issues.
- Getting guidance on how different parts of the system work together.
- Understanding assignment requirements.
- Improving and preparing project documentation.

VS Code was used for editing the project files, while PowerShell was used to run the project, manage dependencies and execute test commands.

## What I changed or rejected

I did not accept every AI suggestion without checking it.

Some suggestions needed adjustments to match my existing project structure and assignment requirements. I reviewed the suggested fixes and changed them where necessary rather than copying everything directly.

I also made sure that documentation described the actual system instead of including features or behaviour that I had not implemented.

The final implementation and decisions are my responsibility.

## What I verified, and how

I checked my work using the provided project tests and development tools.

My verification included:
- Running the project commands through PowerShell.
- Checking test results and fixing errors when they appeared.
- Reviewing code changes in VS Code.
- Checking TypeScript errors and correcting them.
- Comparing the documentation with the assignment requirements.
- Running stage-specific tests to check the relevant requirements.

I understand that passing individual tests does not guarantee that every part of the system works correctly, so the implementation and its behaviour must also be reviewed.
